## Слайд 3 — Задача

# Зачем WISLA АРМ

- Единый **реестр** рабочих станций (Linux + Windows)
- **Метрики** CPU, RAM, диск — в реальном времени и история
- **Инциденты** по порогам (как в Zabbix-шаблонах)
- **Алерты** оператору (UI, Email, Telegram)
- Подготовка к масштабу **до 5000 АРМ**

*Заметка:* «Центральная WISLA — в v2; сегодня автономный модуль мониторинга АРМ.»

## Слайд 6 — Агент

# Агент wisla-arm-agent

- **Go** — один код для Linux и Windows  
- Сбор: CPU, RAM, диск (gopsutil)  
- Batch каждые 30–60 с → `POST /api/v1/agent/ingest`  
- Логи warning/error, события BSoD  
- Авто-регистрация АРМ в реестре  

*Заметка:* «На демо — реальные VM, не симуляция.»
